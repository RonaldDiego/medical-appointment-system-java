# Medical Appointment System

Console-based medical appointment management system developed with Java, applying object-oriented programming principles.

## Features

- Register patients
- Register doctors
- Schedule medical appointments
- Display registered patients
- Display registered doctors
- Display scheduled appointments

## Technologies

- Java
- Object-Oriented Programming (OOP)

## Project Structure
src/
└── sistemacitamedicas/
├── Main.java
├── Paciente.java
├── Doctor.java
├── Cita.java
└── Clinica.java

## Concepts Practiced

- Classes and objects
- Encapsulation
- Constructors
- Object relationships
- ArrayList collections
- Console application development

## About the Project

This project was developed to practice fundamental Java programming concepts through the creation of a console-based medical appointment management system.

The application allows users to register patients, doctors, and appointments using a menu-based interface.
